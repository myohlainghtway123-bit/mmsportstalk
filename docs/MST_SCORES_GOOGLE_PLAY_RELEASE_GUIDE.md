# MST Scores V1 — Google Play Release Guide & Checklist

This document contains the step-by-step procedures and declarations required to release **MST Scores** on Google Play Console once the Google Play Developer Account is purchased.

---

## 1. Application Identity & Identification

| Field | Value | Notes |
|---|---|---|
| **App Name** | `MST Scores` | Official app name. |
| **Short Description** | Live football scores, fixtures, results & news by Myanmar Sports Talk. | Max 80 characters. |
| **Package / Application ID** | `com.myanmarsportstalk.mst` | **Must match exactly** (`app.json`). |
| **Default Language** | English (United States) / Burmese | Primary language en-US, with Burmese translation. |
| **Category** | Sports | Google Play Store category. |
| **Tags** | Sports, Soccer, Football, Live Scores, News | Store search discovery. |

---

## 2. Release Artifact & Signing

* **Production Artifact**: Google Play App Bundle (`.aab`) generated by EAS Build (`production` profile).
* **Play App Signing**: Opt-in to **Google Play App Signing** (recommended and default for all new apps). Google manages the master app signing key while EAS uses its generated upload keystore.
* **Architecture**: Universal Hermes bytecode bundle supporting `arm64-v8a`, `armeabi-v7a`, `x86_64`.

## 3. Policy & Compliance Declarations

Base these entries on the audited application behavior:

### A. Privacy Policy & Legal URLs
* **Privacy Policy URL**: `https://myanmarsportstalk.com/privacy`
* **Terms of Service**: `https://myanmarsportstalk.com/terms`
* **Account / Data Deletion URL**: `https://myanmarsportstalk.com/account-deletion`

### B. App Access (Login Credentials for Reviewers)
* Select: **"All or some functionality in my app is restricted"**.
* Provide test credentials for Google Play App Review:
  * **Email**: `qa1@myanmarsportstalk.com` (or designated reviewer account)
  * **Instructions**: "Sign in via Email OTP. An OTP code is dispatched, or the reviewer can use the app fully as a Guest (all scores, fixtures, standings, match previews, and news are publicly accessible without authentication)."

### C. Ads Declaration
* Select: **"Yes, my app contains ads"**.
* The app integrates Google Mobile Ads (`react-native-google-mobile-ads`) with non-intrusive AdMob banners on the news surface, adhering to UMP (User Messaging Platform) consent for EEA users.

### D. Content Rating
* Questionnaire Category: **"Utility, Productivity, Communication, or Other"** / **"News or Sports"**.
* Violence / Sex / Gambling / Controlled Substances: **No**.
* Does the app feature real-money gambling? **NO**.
  * *Note: MST Tips and Match Vote BFF are purely informational football editorial and user voting surfaces; no real money betting, wager placement, or bookmaker integration occurs in the app.*
* Expected Rating: **PEGI 3 / Everyone (ESRB) / 12+ (Google Play standard for sports news & user discussion)**.

### E. Target Audience & Content
* Target Age: **13 and older** (13–15, 16–17, 18+).
* Appeal to Children: Select **"No"** (app is not designed primarily for young children).

### F. Data Safety Declaration
Base on active source code and library analysis:
1. **Data Collected**:
   * **Personal Info**: Email address (only when user voluntarily signs in for cross-device sync); User Name/Avatar (optional).
   * **App Activity**: User favorites (selected teams/competitions saved to profile); Match vote responses.
   * **Device or Other Identifiers**: Device push token (for opted-in match alert notifications via Expo Notifications); Advertising ID (collected by Google AdMob SDK for ad serving/fraud prevention).
2. **Data Usage**:
   * App functionality (account sync, notifications).
   * Personalization (custom favorites and alerts).
   * Advertising (Google AdMob).
3. **Data Security**:
   * All data is transmitted over encrypted HTTPS connections (`tls 1.3`).
   * Authentication session tokens are stored in hardware-backed secure storage (`expo-secure-store`).
   * Users can request data deletion via `https://myanmarsportstalk.com/account-deletion`.

## 4. Store Listing Assets Checklist

Prepare these graphic assets before publishing:

1. **App Icon**: 512 x 512 px, 32-bit PNG with alpha (assets available at `assets/icon.png`).
2. **Feature Graphic**: 1024 x 500 px, JPG or 24-bit PNG (no alpha).
3. **Phone Screenshots**: Minimum 2 screenshots, 16:9 or 9:16 aspect ratio (e.g. 1080 x 1920 or 1080 x 2400):
   * Screen 1: Live Scores & Match List
   * Screen 2: Match Center & Detailed Insights
   * Screen 3: Football News & Editorial Articles
   * Screen 4: Favorites & Standings

## 5. Release Workflow (When Account is Ready)

1. Log in to [Google Play Console](https://play.google.com/console).
2. Click **Create app**:
   * Name: `MST Scores`
   * Default language: `English (United States)`
   * App or Game: `App`
   * Free or Paid: `Free`
3. Complete **App Content** tasks (Privacy policy, Ads, App access, Content rating, Target audience, Data safety).
4. Go to **Testing > Closed testing** or **Internal testing**:
   * Create a new release.
   * Upload the production `.aab` file created by EAS.
   * Set Release Name: `1.5.2 (13)` (or current version).
   * Add Release Notes (Burmese and English):
     > *EN: Live football scores, match insights, breaking sports news, and personalized favorites by Myanmar Sports Talk.*
     > *MY: မြန်မာစပေါ့တခ် ပရိသတ်များအတွက် တိုက်ရိုက်ဘောလုံးရလဒ်များ၊ ပွဲစဉ်အချက်အလက်များနှင့် သတင်းများ။*
5. Review and roll out release to testers.
6. Once verified in internal/closed testing, promote the release to **Production**.
